# 🧩 Smart Maze Solver

Smart Maze Solver is an interactive web-based application built using **Python and Streamlit** that visualizes how different pathfinding algorithms work in a grid-based maze. Users can design custom mazes and observe how algorithms explore paths and reach the destination in real time.

---

##  Features

- Interactive **maze editor** (start, end, walls, weighted cells)  
- Supports multiple algorithms:
  - Breadth-First Search (BFS)  
  - Depth-First Search (DFS)  
  - Dijkstra’s Algorithm  
  - A* Search  
- **Real-time visualization** of algorithm execution  
- Highlights **visited nodes and final path**  
- Supports both **unweighted and weighted mazes**  
- **Algorithm comparison mode** with performance metrics  

---

##  Technologies Used

- **Python** – Core programming language  
- **Streamlit** – Interactive web interface  
- **Collections (deque)** – BFS implementation  
- **Heapq** – Priority queue for Dijkstra and A*  
- **HTML & CSS** – UI styling
